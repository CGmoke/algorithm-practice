# [1871. 跳跃游戏 VII](https://leetcode.cn/problems/jump-game-vii/)

给你一个下标从 **0** 开始的二进制字符串 `s` 和两个整数 `minJump` 和 `maxJump` 。一开始，你在下标 `0` 处，且该位置的值一定为 `'0'` 。当同时满足如下条件时，你可以从下标 `i` 移动到下标 `j` 处：

- `i + minJump <= j <= min(i + maxJump, s.length - 1)` 且
- `s[j] == '0'`.

如果你可以到达 `s` 的下标 `s.length - 1` 处，请你返回 `true` ，否则返回 `false` 。

**示例 1：**

```
输入：s = "011010", minJump = 2, maxJump = 3
输出：true
解释：
第一步，从下标 0 移动到下标 3 。
第二步，从下标 3 移动到下标 5 。
```

**示例 2：**

```
输入：s = "01101110", minJump = 2, maxJump = 3
输出：false
```

**提示：**

- `2 <= s.length <= 105`
- `s[i]` 要么是 `'0'` ，要么是 `'1'`
- `s[0] == '0'`
- `1 <= minJump <= maxJump < s.length`



```python
class Solution:
    def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
        n = len(s)
        canReach = [False]*n
        canReach[0]=True
        j=1
        for i , ch in enumerate(s):
            if ch=='0' and canReach[i]==True:
                mx = min(i+maxJump,n-1)
                j = max(j,i+minJump)
                while j<=mx:
                    canReach[j] = True
                    j+=1
                if j==n:
                    break
        return s[-1]=='0' and canReach[-1]
```

**同向双指针**

在不断往右跳的过程中，窗口 [i+minJump,i+maxJump] 也在向右滑动。窗口右边的还没有被我们访问到的下标，都在 s 的后缀中。

于是，用一个下标 j 表示：还没有访问到的下标为 [j,n)。初始值 j=1。

当我们跳到下标 i 时，暴力标记 [max(j,i+minJump),i+maxJump] 中的下标都被访问到。然后更新 j 为 i+maxJump+1。

由于 j 只会增大，不会减小，所以总体时间复杂度是 O(n)。



## 问题回顾

给定一个由 `'0'` 和 `'1'` 组成的字符串 `s`，从下标 `0` 出发，每次只能跳到值为 `'0'` 的位置，跳跃距离必须在 `[minJump, maxJump]` 范围内。判断能否到达最后一个下标 `n-1`。

------

## 状态定义

- `canReach[i]`（布尔值）：表示从起点能否到达位置 `i`。
- 初始：`canReach[0] = True`。
- 目标：`canReach[n-1]` 是否为 `True`。

直接转移：对于每个已可到达的位置 `i`（`s[i]=='0'` 且 `canReach[i]==True`），将区间 `[i+minJump, i+maxJump]` 内所有值为 `'0'` 的位置标记为可到达。
但若朴素实现，每个 `i` 都要遍历一个长度为 `(maxJump-minJump)` 的区间，最坏 O(n²)。

------

## 核心优化：双指针维护“连续未标记段”

代码中引入指针 `j`，表示**下一个需要标记的位置**，初始 `j=1`。
当我们处理一个可到达位置 `i` 时：

- 计算能影响的最右边界 `mx = min(i+maxJump, n-1)`。
- 确定新的标记起点：`j = max(j, i+minJump)`，即从“已标记过的最右位置的下一个”和“当前区间左端点”中取较大值，**避免重复标记**。
- 用 `while j <= mx` 将 `canReach[j]` 全部设为 `True`，同时 `j` 自增。这相当于**一次性覆盖所有之前未标记的位置**。
- 如果 `j` 已经到达 `n`，说明后续所有位置都已标记完毕，可提前结束循环。

这样，每个下标**最多被标记一次**，因此总操作次数为 O(n)。

------

## 算法流程

1. 初始化 `canReach[0] = True`，指针 `j = 1`。
2. 遍历字符串 `s`，对每个下标 `i`：
   - 如果 `s[i] == '0'` 且 `canReach[i] == True`（即位置 `i` 可到达），则：
     - 计算可覆盖的区间 `[max(j, i+minJump), min(i+maxJump, n-1)]`。
     - 用 `while` 循环将该区间内所有位置标记为可到达，并更新 `j`。
     - 若 `j == n`，提前退出循环。
3. 最终返回：`s[-1] == '0'` 且 `canReach[-1]`。

------

## 举例说明

```
s = "011010", minJump = 2, maxJump = 3`
初始：`canReach[0]=T, j=1
```

- i=0：`s[0]='0'`且可到达。区间 `[max(1,0+2)=2, min(0+3,5)=3]`，标记 `j=2,3` 为 `T`，`j` 变为 `4`。
- i=1：`s[1]='1'` 跳过。
- i=2：`s[2]='1'` 跳过（`canReach[2]=T` 但字符为`1`不能跳）。
- i=3：`s[3]='0'`且可到达。区间 `[max(4,3+2)=5, min(3+3,5)=5]`，标记 `j=5` 为 `T`，`j` 变为 `6`。`j==n` 提前结束。

最后 `canReach[5]=T`，且 `s[5]='0'`，返回 `True`。

------

## 复杂度分析

- **时间复杂度**：O(n)。每个位置 `j` 只会被标记一次，`while` 循环总次数不超过 `n`。外层 `for` 循环遍历也是 O(n)。
- **空间复杂度**：O(n)，`canReach` 数组的长度。

------

## 总结

该解法本质上是一种**BFS + 剪枝**的优化：

- 不需要队列，直接按顺序扫描即可，因为转移区间是连续的且跳跃方向向前。
- 用指针 `j` 记录“已标记前缀”的右边界，避免对同一个位置反复赋值。
- 这样就将“区间更新”压缩成线性时间，比通常的滑动窗口前缀和优化更直观易懂（虽然也可以用前缀和记录可到达数量，但此处的实现更简洁）。

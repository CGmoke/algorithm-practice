# [853. 车队](https://leetcode.cn/problems/car-fleet/)

在一条单行道上，有 `n` 辆车开往同一目的地。目的地是几英里以外的 `target` 。

给定两个整数数组 `position` 和 `speed` ，长度都是 `n` ，其中 `position[i]` 是第 `i` 辆车的位置， `speed[i]` 是第 `i` 辆车的速度(单位是英里/小时)。

一辆车永远不会超过前面的另一辆车，但它可以追上去，并以较慢车的速度在另一辆车旁边行驶。

**车队** 是指并排行驶的一辆或几辆汽车。车队的速度是车队中 **最慢** 的车的速度。

即便一辆车在 `target` 才赶上了一个车队，它们仍然会被视作是同一个车队。

返回到达目的地的车队数量 。

 

**示例 1：**

**输入：**target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]

**输出：**3

**解释：**

- 从 10（速度为 2）和 8（速度为 4）开始的车会组成一个车队，它们在 12 相遇。车队在 `target` 形成。
- 从 0（速度为 1）开始的车不会追上其它任何车，所以它自己是一个车队。
- 从 5（速度为 1） 和 3（速度为 3）开始的车组成一个车队，在 6 相遇。车队以速度 1 移动直到它到达 `target`。

**示例 2：**

**输入：**target = 10, position = [3], speed = [3]

**输出：**1

**解释：**

只有一辆车，因此只有一个车队。

**示例 3：**

**输入：**target = 100, position = [0,2,4], speed = [4,2,1]

**输出：**1

**解释：**

- 从 0（速度为 4） 和 2（速度为 2）开始的车组成一个车队，在 4 相遇。从 4 开始的车（速度为 1）移动到了 5。
- 然后，在 4（速度为 2）的车队和在 5（速度为 1）的车成为一个车队，在 6 相遇。车队以速度 1 移动直到它到达 `target`。





```python
class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        n = len(position)
        res = 0
        st = []
        cars = sorted(zip(position,speed))
        for i,(p,s) in enumerate(cars):
            time =(target-p)/s
            while st and time>=st[-1]  :
                st.pop()
            
            st.append(time)
            # print(st)
        return len(st)

```

## 1. 问题目标

在一条单行道上，给定每辆车的起始位置 `position[i]` 和速度 `speed[i]`（位置越大的车越靠近终点 `target`）。后面的车如果更快，会在终点前追上前面的车，形成**车队**（以车队中最慢车的速度前进）。
要求计算最终有多少个车队到达终点。

------

## 2. 算法思路

### ① 排序：按位置升序



```python
cars = sorted(zip(position, speed))
```



将 `(位置, 速度)` 对按**位置从小到大**排序。
即先处理**离终点远的车（后面的车）**，后处理**离终点近的车（前面的车）**。

### ② 到达时间计算

对于每辆车，计算它**单独开到终点所需的时间**：



```python
time = (target - p) / s
```



### ③ 单调栈维护车队到达时间

使用一个栈 `st`，但这里它不存放车辆索引，而是存放**车队的到达时间**。

- **入栈条件**：当前车的到达时间 `time` 与栈顶比较：
  - **如果 `time >= st[-1]`**：说明当前车（前车）比栈顶车队（后车）**更慢或相等**。此时栈顶代表的后方车队（更快）一定会追上当前前车，两者合并成一个车队。
    于是弹出栈顶（代表后车被合并），继续向前检查，直到栈空或 `time < st[-1]`（即当前车比栈顶车队更快，不会追尾）。
  - 最后将当前车的 `time` 压入栈中。

这样，栈中始终保持一个**从栈底到栈顶严格递减**的到达时间序列（即越靠近栈顶时间越小，代表越靠近当前处理位置的车队越快）。
最终栈的大小就是无法再合并的独立车队数量。

### ④ 为什么从前往后也能工作？

常见的解法是**按位置降序**，从离终点近的车往远的车处理，若后车时间 ≤ 前车时间则合并。
这里的从前往后 + 弹出栈顶的写法是等价的：

- 当处理到一个“前车”（位置更大），如果它的时间 ≥ 栈顶（后方车队），相当于后方车队一定会在终点前追上它。合并后车队到达时间取较慢者（即当前前车的时间），所以弹出栈顶，最终压入当前时间。
- 栈的单调性保证了每个车队只被计算一次，且所有可能的合并都被执行。

------

## 3. 举例演示

```python
target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]
```

排序后 `cars`：
`(0,1,t=12)`, `(3,3,t=3)`, `(5,1,t=7)`, `(8,4,t=1)`, `(10,2,t=1)`

遍历：

- `i=0, t=12`：栈空 → 压栈，`st = [12]`
- `i=1, t=3`：`3 < 12` 不弹 → 压栈，`st = [12, 3]`
- `i=2, t=7`：`7 >= 3` 弹出3；`7 < 12` 停止，压栈，`st = [12, 7]`
- `i=3, t=1`：`1 < 7` 不弹，压栈，`st = [12, 7, 1]`
- `i=4, t=1`：`1 >= 1` 弹出1；`1 < 7` 停止，压栈，`st = [12, 7, 1]`

最终 `st` 有 3 个元素 → 返回 3，正确。

------

## 4. 复杂度分析

- **时间复杂度**：O(n log n)，瓶颈在排序。
- **空间复杂度**：O(n)，用于存储配对后的 `cars` 和栈。

------

## 5. 与“从后往前”解法的对比

| 方法     | 遍历顺序             | 栈维护内容 | 合并条件                                    |
| :------- | :------------------- | :--------- | :------------------------------------------ |
| 标准解法 | 位置降序（从前往后） | 到达时间   | 当前时间 ≤ 栈顶则合并（不压栈）             |
| 本代码   | 位置升序（从后往前） | 到达时间   | 当前时间 ≥ 栈顶则弹出栈顶，最后压入当前时间 |

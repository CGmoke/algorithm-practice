# [654. 最大二叉树](https://leetcode.cn/problems/maximum-binary-tree/)

给定一个不重复的整数数组 `nums` 。 **最大二叉树** 可以用下面的算法从 `nums` 递归地构建:

1. 创建一个根节点，其值为 `nums` 中的最大值。
2. 递归地在最大值 **左边** 的 **子数组前缀上** 构建左子树。
3. 递归地在最大值 **右边** 的 **子数组后缀上** 构建右子树。

返回 *`nums` 构建的* ***最大二叉树\*** 。

```
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,2,0,null,null,1]
解释：递归调用如下所示：
- [3,2,1,6,0,5] 中的最大值是 6 ，左边部分是 [3,2,1] ，右边部分是 [0,5] 。
    - [3,2,1] 中的最大值是 3 ，左边部分是 [] ，右边部分是 [2,1] 。

        - [2,1] 中的最大值是 2 ，左边部分是 [] ，右边部分是 [1] 。
            - 空数组，无子节点。
            - 只有一个元素，所以子节点是一个值为 1 的节点。
    - [0,5] 中的最大值是 5 ，左边部分是 [0] ，右边部分是 [] 。
        - 只有一个元素，所以子节点是一个值为 0 的节点。
        - 空数组，无子节点。
```

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def constructMaximumBinaryTree(self, nums: List[int]) -> Optional[TreeNode]:
        st = []
        for num in nums:
            node = TreeNode(num)
            while st and  st[-1].val <num:
                node.left = st.pop()
            if st:
                st[-1].right = node
            st.append(node)
        return st[0]
```



## 1. 算法核心思想：笛卡尔树的单调栈构建

最大二叉树实际上是一棵**笛卡尔树**：树的中序遍历就是原数组，且树满足堆性质（每个节点的值大于其左右子树中所有节点的值）。
对于笛卡尔树，有一个经典的线性构建算法：**从左到右遍历数组元素，保持一个单调递减的栈，栈中节点代表尚未确定右孩子的候选链**。

### 算法步骤（对应代码逻辑）：

1. 初始化空栈 `st`。
2. 遍历数组中的每个值 `num`：
   - 为 `num` 创建新节点 `node`。
   - **不断弹出栈中值小于 `num` 的节点**，并将最后一个弹出的节点设为 `node.left`。
     这些被弹出的节点都在 `num` 的左侧，且都比 `num` 小，因此它们应该属于 `num` 的左子树。由于它们在栈中是递减的，弹出顺序恰好形成一条右斜链，`node.left` 连接到这条链的顶端（最大值），正好符合最大二叉树的结构。
   - **如果此时栈非空**，说明栈顶节点是左侧第一个大于 `num` 的节点。此时 `num` 比它小，按照规则，`num` 应该成为这个栈顶节点的右孩子，故执行 `st[-1].right = node`。
   - 将 `node` 压入栈中。
3. 遍历结束后，栈底元素就是全数组的最大值，即整棵树的根节点（返回 `st[0]`）。

### 为什么这是正确的？

最大二叉树有一个关键性质：对于数组中的任意元素 `x`，它在树中的父节点是 **左侧第一个比它大的元素** 和 **右侧第一个比它大的元素** 中较小的那个。
本算法通过单调栈巧妙地维护了“左侧第一个更大”的关系：

- 当 `node` 大于栈顶时，它不断弹出栈顶，这些被弹出的节点都是 `node` 左侧且比 `node` 小的节点，它们最终的“左侧第一个更大”就是 `node`（因为当前 `node` 比它们大，且更靠右，比它们更早遇到右侧更大值）。
- 弹出停止后，栈顶节点就是 `node` 的左侧第一个更大值。此时 `node` 成为栈顶的右孩子，意味着 `node` 的父节点暂时被认为是这个左侧更大值。如果之后遇到一个更大的数，`node` 可能会被调整（通过弹出改变结构），最终每个节点都会正确连接到它真正的父节点。

整个过程就像“右链调整”算法，确保所有节点都能在 O(n) 时间内找到自己的位置。

## 2. 示例演示

以 `nums = [3,2,1,6,0,5]` 为例：

| 当前 num | 操作                                                         | 栈（节点值） |
| :------- | :----------------------------------------------------------- | :----------- |
| 3        | 栈空，压入                                                   | [3]          |
| 2        | 2<3，不弹；`3.right=2`，压栈                                 | [3,2]        |
| 1        | 1<2，`2.right=1`，压栈                                       | [3,2,1]      |
| 6        | 弹出1（`6.left=1`），弹出2（`6.left=2`），弹出3（`6.left=3`）；栈空，压栈 | [6]          |
| 0        | 0<6，`6.right=0`，压栈                                       | [6,0]        |
| 5        | 弹出0（`5.left=0`）；栈非空，`6.right=5`，压栈               | [6,5]        |

最终栈底 `6` 就是根节点，构造出的树与题目要求完全一致。

## 3. 复杂度分析

- **时间复杂度**：O(n)。每个元素入栈一次、出栈一次，总操作次数与数组长度成正比。
- **空间复杂度**：O(n)。栈和树节点的数量均为 n。

------

## 4. 总结

该算法利用**最大二叉树就是笛卡尔树**这一本质，通过**单调递减栈**维护“右链候选节点”，在一次线性扫描中不断调整节点关系，直接构造出完整的树。这种方法将递归分治的最坏 O(n²) 优化到了严格的 O(n)，是处理此类问题的经典技巧。

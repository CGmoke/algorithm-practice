# [768. 最多能完成排序的块 II](https://leetcode.cn/problems/max-chunks-to-make-sorted-ii/)

给你一个整数数组 `arr` 。

将 `arr` 分割成若干 **块** ，并将这些块分别进行排序。之后再连接起来，使得连接的结果和按升序排序后的原数组相同。

返回能将数组分成的最多块数？

 

**示例 1：**

```
输入：arr = [5,4,3,2,1]
输出：1
解释：
将数组分成2块或者更多块，都无法得到所需的结果。 
例如，分成 [5, 4], [3, 2, 1] 的结果是 [4, 5, 1, 2, 3]，这不是有序的数组。 
```

**示例 2：**

```
输入：arr = [2,1,3,4,4]
输出：4
解释：
可以把它分成两块，例如 [2, 1], [3, 4, 4]。 
然而，分成 [2, 1], [3], [4], [4] 可以得到最多的块数。 
```



```python
class Solution:
    def maxChunksToSorted(self, arr: List[int]) -> int:
        res = []
        st=[]
        for x in arr:
            temp = x
            while st and st[-1]>x:
                temp = max(temp,st.pop())
            st.append(temp)
            print(st)
        return len(st)
```



## 1. 核心算法思想

### ① 栈中存储每个“块”的最大值

我们用一个栈 `st` 来保存**当前已分割的每个块的最大值**，并始终保证这些最大值是**严格递增**的（非递减也可，但这里用递增，因为相等时不合并）。

- 栈顶代表**最右边一块**的最大值。
- 栈底代表**最左边一块**的最大值。

### ② 遍历元素，决定分块或合并

对于当前元素 `x`，我们尝试将它作为**新的一块**的开头。这一块当前的（临时）最大值设为 `temp = x`。

然后检查栈顶：

- 如果 **栈顶元素 ≤ x**：说明前一块的最大值不大于当前块的最小值（当前块一开始只有 `x`，最大值至少为 `x`），两个块可以独立存在，排序后不会互相干扰。
  于是直接将 `temp`（即 `x`）压入栈中，形成新块。
- 如果 **栈顶元素 > x**：说明前一块的最大值比当前元素大。如果这两个块分开排序，前一块的大值会跑到后面去，结果会比 `x` 大，从而破坏整体有序性（因为整体排序后 `x` 应该在前面那个大值的前面）。因此，**当前块必须与前面的块合并**，直到栈顶块的的最大值 ≤ `x`，或者栈空。

合并时，我们不断弹出栈顶，同时更新 `temp` 为这些弹出块与 `x` 中的最大值（因为合并后的块的最大值可能是这些数中的最大者）。
合并停止时，再将 `temp` 压栈，代表一个合并后的、更大的块。

### ③ 最终栈的大小就是答案

因为栈中每个元素代表一个独立块的最大值，且这些块从左到右的最大值递增（满足整体排序要求）。栈中元素个数即为最多能分出的块数。

------

## 2. 举例说明

以 `arr = [2, 1, 3, 4, 4]` 为例模拟：

| 当前 x | temp | 栈（最大值） | 操作说明                                                     |
| :----- | :--- | :----------- | :----------------------------------------------------------- |
| 2      | 2    | `[2]`        | 栈空，压入 2                                                 |
| 1      | 1    | `[2]`        | 栈顶 2 > 1，合并：弹出 2，temp 更新为 max(1,2)=2，栈空后压入 2 → `[2]` |
| 3      | 3    | `[2]`        | 栈顶 2 ≤ 3，不合并，直接压入 3 → `[2, 3]`                    |
| 4      | 4    | `[2, 3]`     | 栈顶 3 ≤ 4，压入 4 → `[2, 3, 4]`                             |
| 4      | 4    | `[2, 3, 4]`  | 栈顶 4 ≤ 4，不合并，压入 4 → `[2, 3, 4, 4]`                  |

最终栈为 `[2, 3, 4, 4]`，长度 4，返回 4，正确。

再例如 `arr = [5, 4, 3, 2, 1]`（严格递减）：

- 5 → `[5]`
- 4 → 5 > 4，合并得 max(4,5)=5 → `[5]`
- 3 → 5 > 3，合并得 5 → `[5]`
- ... 最终栈 `[5]`，长度 1，正确（整个数组必须一块）。

------

## 3. 正确性分析

- **必要性**：如果前一个块的最大值大于当前元素 `x`，这两块必须合并，否则排序后前块的大值会出现在 `x` 后面，违反最终有序性。
- **充分性**：合并后栈中元素保持递增，保证了每个块的最大值 ≤ 下一块的最小值（下一块的第一个元素即下一次遍历的 `x`，且下一块的最大值至少为这个 `x`，若 `x` ≥ 栈顶，则不会合并）。因此每个块排序后，其所有元素都 ≤ 下一块的最小元素，整体拼接自然有序。
- **最优性**：每次遇到栈顶 > x 就合并，是在“被迫”情况下才合并，这保证了尽可能多的小块，是一种贪心思想。

------

## 4. 复杂度

- **时间复杂度**：O(n)，每个元素入栈一次、出栈最多一次。
- **空间复杂度**：O(n)，栈最深时可能存储所有块的最大值。

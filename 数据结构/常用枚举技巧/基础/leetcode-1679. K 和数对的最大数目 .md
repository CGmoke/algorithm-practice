# [1679. K 和数对的最大数目](https://leetcode.cn/problems/max-number-of-k-sum-pairs/)

[中等]

给你一个整数数组 `nums` 和一个整数 `k` 。

每一步操作中，你需要从数组中选出和为 `k` 的两个整数，并将它们移出数组。

返回你可以对数组执行的最大操作数。 

**示例 1：**

```
输入：nums = [1,2,3,4], k = 5
输出：2
解释：开始时 nums = [1,2,3,4]：
- 移出 1 和 4 ，之后 nums = [2,3]
- 移出 2 和 3 ，之后 nums = []
不再有和为 5 的数对，因此最多执行 2 次操作。
```

**示例 2：**

```
输入：nums = [3,1,3,4,3], k = 6
输出：1
解释：开始时 nums = [3,1,3,4,3]：
- 移出前两个 3 ，之后nums = [1,4,3]
不再有和为 6 的数对，因此最多执行 1 次操作。
```

**提示：**

- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 109`
- `1 <= k <= 109`

```python
class Solution:
    def maxOperations(self, nums: List[int], k: int) -> int:
        res = 0
        cnt = defaultdict(int)
        for i in nums:
            if cnt[k-i]:
                cnt[k-i]-=1
                res+=1
            else:
                cnt[i]+=1
        return res
            
```

算法思想：

用哈希表 `cnt` 记录「当前尚未配对的数字 -> 出现次数」。从左到右枚举每个数字 `i`：

- 若 `k - i` 已经在 `cnt` 中存在（即之前出现过还没被配对的补数），就把它们配成一对：`res += 1`，并把 `k - i` 的计数减 1。
- 否则说明 `i` 暂时找不到配对，把它自己计入 `cnt`，等待后面的补数来和它配对。

因为每个数字只会进入 `cnt` 一次、也只会被消耗一次，所以不会出现同一个元素被重复使用的情况。无论先遇到的是 `i` 还是 `k - i`，配对结果都相同，因此这种「能配就配、不能配就先存着」的贪心策略一定能取到最多的对数。

注意 `cnt[k - i]` 为 0 时为假值，所以不用单独判断 `k - i` 是否在字典里。另外当 `2 * i == k`（比如 `k` 为偶数、`i = k / 2`）时，同一个值只有在出现两次时才会配对成功，也符合题意。

#### 复杂度分析

- 时间复杂度：O(*n*)，其中 *n* 为 *nums* 的长度，每个元素只被处理一次，哈希表单次操作均摊 O(1)。
- 空间复杂度：O(*n*)，最坏情况下所有元素都不配对，全部存入哈希表。

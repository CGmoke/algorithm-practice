## 一、链表基础

### 1. 什么是链表？

链表是由一系列**节点**组成的线性结构，每个节点包含**数据**和**指向下一个节点的指针**。节点在内存中不连续，通过指针连接。

**节点结构（单链表）**：



```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```



### 2. 链表类型

| 类型         | 特点                                           |
| :----------- | :--------------------------------------------- |
| **单链表**   | 每个节点只有一个 `next` 指针，只能单向遍历     |
| **双链表**   | 每个节点有 `prev` 和 `next`，可双向遍历        |
| **循环链表** | 尾节点指向头节点（单循环）或头尾互指（双循环） |

### 3. 链表 vs 数组

| 操作                  | 数组           | 链表                     |
| :-------------------- | :------------- | :----------------------- |
| 随机访问              | O(1)           | O(n)                     |
| 头插/头删             | O(n)           | O(1)                     |
| 尾插/尾删（有尾指针） | O(1)           | O(1)                     |
| 中间插入/删除         | O(n)           | 找到位置 O(n)，操作 O(1) |
| 内存                  | 连续，可能浪费 | 分散，有指针开销         |

## 二、基础操作模板（单链表）

### 1. 遍历

python

```python
cur = head
while cur:
    print(cur.val)
    cur = cur.next
```



### 2. 头插法

python

```python
def insert_head(head, val):
    new_node = ListNode(val)
    new_node.next = head
    return new_node   # 返回新头
```



### 3. 尾插法（有尾指针）

python

```python
def insert_tail(tail, val):
    new_node = ListNode(val)
    if tail:
        tail.next = new_node
    return new_node   # 返回新尾
```



### 4. 删除节点（假设删除给定节点的下一节点）

python

```python
# 已知 node，删除 node.next
node.next = node.next.next
```



**注意**：若要删除当前节点且不知道前驱，可以“偷梁换柱”（拷贝下一节点的值再删下一节点）。

### 5. 反转链表（原地）

python

```python
def reverse(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev
```

## 三、进阶技巧与经典题目

### 1. 双指针（快慢指针）

- **找中点**：快指针每次走两步，慢指针走一步，快指针到末尾时慢指针在中点。

  python

  ```python
  slow = fast = head
  while fast and fast.next:
      slow = slow.next
      fast = fast.next.next
  # slow 即为中点（前半段偏左或偏右取决于循环条件）
  ```

  

- **环检测**：快慢指针相遇则有环。

- **找环入口**：相遇后，将一头指针移回起点，两指针同步走，再次相遇点即入口。

- **倒数第 K 个节点**：快指针先走 K 步，然后快慢同步走，快指针到末尾时慢指针在倒数第 K 个。

### 2. 哑节点（Dummy Node）

在头节点可能被修改的情况下，使用虚拟头节点可以简化边界处理（如合并、删除）。

python

```python
dummy = ListNode(0)
dummy.next = head
cur = dummy
# 操作链表...
return dummy.next
```



### 3. 链表排序

- **归并排序**（最适合链表）：递归分割（找中点），分别排序，合并两个有序链表。

- 合并两个有序链表模板：

  python

  ```python
  def merge(l1, l2):
      dummy = ListNode()
      cur = dummy
      while l1 and l2:
          if l1.val < l2.val:
              cur.next = l1
              l1 = l1.next
          else:
              cur.next = l2
              l2 = l2.next
          cur = cur.next
      cur.next = l1 or l2
      return dummy.next
  ```

  

### 4. 复杂操作

- **反转部分链表**（区间反转）：定位到反转段前驱，反转指定区间后接回。
- **K 个一组反转**：分段反转，用递归或迭代。
- **链表相交**：消除长度差，双指针走到同一节点或同时为 None。
- **回文链表**：找中点，反转后半段，再比较。

### 5. 深拷贝复杂链表

如带随机指针的链表，用哈希表映射旧节点到新节点，或原地复制（交错插入新节点，再拆分）。

## 四、进阶数据结构（基于链表）

### 1. LRU 缓存（哈希表 + 双向链表）

- 双向链表维护访问顺序（最近使用的在头部，最久未使用的在尾部）。
- 哈希表实现 O(1) 查找。
- get/put 时移动节点到头部，超出容量时删除尾部节点。

### 2. 跳表（Skip List）

- 多层有序链表，通过随机化增加上层索引，实现 O(log n) 的查找、插入、删除。
- Redis 有序集合底层实现之一。

### 3. 邻接表（图）

- 存储图的边，每个顶点维护一个链表（或数组）指向其邻居。

## 五、常见错误与调试技巧

- 空指针：访问 `node.val` 前确保 `node` 非空。
- 断链：插入/删除时先保存后续节点 `nxt = cur.next`，防止丢失。
- 循环依赖：反转链表时记得预先取 `nxt`。
- 多指针操作时，保持指针更新的顺序。
- 利用 `print` 打印指针地址和值辅助调试（或画图）。
